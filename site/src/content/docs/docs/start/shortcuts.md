| Shortcut | Action |
|---|---|
| `⌘K` | Spotlight |
| `⌘1` … `⌘9` | Switch server workspace |
| `⌘O` | All servers |
| `⌘⇧S` | Services |
| `⌘W` · `⌘M` | Close · minimize window |
| `⌘,` | Settings |
| `⌘L` | Lock Davish |
| `⌘S` | Save in the Editor |
| `⌘F` · `⌘[` · `⌘]` · `⌘↑` | Files: search, back, forward, up |
| `⌘U` · `⌘D` | Files: upload, download |
| `⌘⌥S` | Files: copy the selection to another server |
| `⌘⌥L` | Transfers window |

On Windows and Linux, use `Ctrl` instead of `⌘`. Inside a terminal, `Ctrl` shortcuts go to the shell. The **Help** menu in the menu bar lists every command with its shortcut.
