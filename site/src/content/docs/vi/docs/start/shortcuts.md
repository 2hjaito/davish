---
title: Phím tắt
description: Các phím tắt dùng được ở mọi nơi trong Davish.
sidebar:
  order: 4
---

| Phím | Tác dụng |
|---|---|
| `⌘K` | Spotlight |
| `⌘1` … `⌘9` | Chuyển workspace server |
| `⌘0` | Tất cả server |
| `⌘⇧S` | Dịch vụ |
| `⌘W` · `⌘M` | Đóng · thu nhỏ cửa sổ |
| `⌘,` | Cài đặt |
| `⌘L` | Khóa Davish |
| `⌘S` | Lưu trong Editor |
| `⌘F` · `⌘[` · `⌘]` · `⌘↑` | Files: tìm, lùi, tiến, lên thư mục cha |
| `⌘U` · `⌘D` | Files: tải lên, tải xuống |
| `⌘⌥S` | Files: copy mục đang chọn sang server khác |
| `⌘⌥L` | Cửa sổ Chuyển file |

Trên Windows và Linux dùng `Ctrl` thay cho `⌘`. Khi đang ở trong Terminal, phím `Ctrl` thuộc về shell. Menu **Trợ giúp** trên menu bar liệt kê mọi lệnh kèm phím tắt.
