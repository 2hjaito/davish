Toàn bộ giao diện có tiếng Việt, tiếng Anh, tiếng Trung giản thể, tiếng Tây Ban Nha (Tây Ban Nha), tiếng Đức, tiếng Hàn và tiếng Pháp: menu, hộp thoại, trợ giúp, thông báo lỗi, ngày tháng và số. Lần đầu Davish theo ngôn ngữ của máy; sau đó chọn trong Cài đặt → Chung → Ngôn ngữ. Davish khởi động lại để đổi, server tự kết nối lại.
